Choosing tracks by hand: audio track 2 (the stereo tone) and
subtitle track 1, into a Matroska file this time.

$ HandBrakeCLI -i fixture/testcard.mkv -o output/custom.mkv \
    -f av_mkv -e x264 --encoder-preset medium -q 20 \
    --audio 2 --subtitle 1

$ ffprobe -hide_banner output/custom.mkv
  Stream #0:0: Video: h264 (High), yuv420p, 1280x720, 25 fps (default)
  Stream #0:1(eng): Audio: mp3, 44100 Hz, stereo, fltp, 160 kb/s (default)

# The track selection worked -- stereo means track 2, the only
# stereo source -- and the subtitle crossed over (as ASS, the
# subtitle format Matroska files from HandBrake carry). But
# look at the audio codec: MP3, which nobody asked for. With
# no --aencoder named, the choice falls to a default, and the
# default for Matroska is MP3 while the default for MP4 is
# AAC. Name the audio encoder yourself:

$ HandBrakeCLI -i fixture/testcard.mkv -o output/custom-aac.mkv \
    -f av_mkv -e x264 --encoder-preset medium -q 20 \
    --audio 2 --aencoder av_aac --subtitle 1
[13:25:44] mux: track 1, 346 frames, 128216 bytes, 127.58 kbps
[13:25:44] mux: track 2, 2 frames, 114 bytes, 0.11 kbps
